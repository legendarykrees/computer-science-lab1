# Лабораторная работа №1

## Анализ устройства современной информационной системы

**Цель работы:** получить представление об устройстве современных информационных систем на примере
реального цифрового сервиса: выделить компоненты системы, изучить взаимодействие клиентской и серверной
частей с помощью DevTools и описать архитектуру системы.

**Вариант:** 5 — **Notion** (https://www.notion.so) — SaaS-сервис для заметок и управления информацией.
**Сценарий:** создание страницы и добавление блока.

## Результат

- Описан сервис, его аудитория и возможности; выполнен сценарий, сделаны скриншоты интерфейса.
- В DevTools изучены HTML-структура блока, подключаемые ресурсы, локальное хранилище и сетевые запросы;
  разобран запрос сохранения `POST /api/v3/saveTransactionsFanout`.
- Описаны серверные компоненты, внешние сервисы (Cloudflare, Sentry, Splunk, Statsig, hCaptcha и др.)
  и хранилища данных.
- Сценарий описан по шагам: пользователь → интерфейс → клиент → сервер → данные → результат.
- Построена архитектурная схема в draw.io.
